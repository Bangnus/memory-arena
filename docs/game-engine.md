# Game Engine Specification
Version 1.0

---

# Overview

The Game Engine is responsible for controlling the complete game flow.

It is the heart of the backend.

Every game action must go through the Game Engine.

The Game Engine is the only component allowed to change the game state.

# Engine Rules

Never use global variables.

Never calculate winner inside controllers.

Never write database outside services.

Never emit Socket.IO directly inside controllers.

Controllers only call GameEngineService.

---

# Development Rules

Every new game mode must extend GameEngine.

Never duplicate logic.

All business rules belong to the engine.

The engine is the only authority for game execution.
