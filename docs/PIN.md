# 📌 คู่มือและตารางการต่อสายวงจร Memory Arena (Hardware Wiring Guide)

เอกสารสรุปแผนผังการต่อสายไฟของเครื่องเล่นเกม **Memory Arena** สำหรับช่างประกอบฮาร์ดแวร์  
อุปกรณ์หลักประกอบด้วย:
1. **ESP32 Dev Module (แนะนำรุ่น ESP32-WROOM-32)**
2. **โมดูลขยายขา PCF8575 (I2C 16 ช่อง)**
3. **หลอดไฟ LED รวม 12 ดวง**:
   - 🎯 **ไฟหลักตรงกลางแสดงโจทย์**: 4 ดวง (แดง, เขียว, น้ำเงิน, เหลือง)
   - 🔴 **ไฟฝั่งผู้เล่น 1 (P1)**: 4 ดวง (แดง, เขียว, น้ำเงิน, เหลือง)
   - 🔵 **ไฟฝั่งผู้เล่น 2 (P2)**: 4 ดวง (แดง, เขียว, น้ำเงิน, เหลือง)
4. **ปุ่มกดเล่นเกม 8 ปุ่ม**: ฝั่งละ 4 ปุ่ม (แดง, น้ำเงิน, เขียว, เหลือง)
5. **ปุ่มควบคุม 4 ปุ่ม**: START, NEXT, PREV, RESTART
6. **Passive Buzzer (หรือโมดูล Passive Buzzer) 1 ตัว**

---

## 1. การเชื่อมต่อโมดูล PCF8575 เข้ากับ ESP32 (I2C Bus)

เชื่อมต่อสายสัญญาณ 4 เส้นระหว่างบอร์ด ESP32 และโมดูล PCF8575:

| ขาบนโมดูล PCF8575 | ขาบนบอร์ด ESP32 | คำอธิบาย |
| :--- | :--- | :--- |
| **VCC** | **5V (VIN)** หรือ **3V3** | ไฟเลี้ยงโมดูล |
| **GND** | **GND** | กราวด์ร่วม |
| **SDA** | **GPIO 21** | ข้อมูล I2C Data |
| **SCL** | **GPIO 22** | สัญญาณนาฬิกา I2C Clock |

> ⚠️ **หมายเหตุสำหรับการตั้งค่า Address บน PCF8575**:  
> ขา **A0, A1, A2** บนโมดูล PCF8575 ให้ต่อลง **GND** ทั้งหมด (จะได้ I2C Address = `0x20`)

---

## 2. การต่อหลอดไฟ LED ทั้งหมด 12 ดวง เข้ากับ PCF8575 (P0 – P11)

> 💡 **รูปแบบการต่อ LED (Active-LOW)**:  
> PCF8575 สามารถ Sink กระแส (ดึงกระแสลง GND) ได้ดีถึง ~25mA ต่อขา จึงต่อแบบ Active-LOW:
> - **ขาบวก (Anode / ขายาว)** ของ LED ต่อกับไฟบวก **5V / 3.3V** (ผ่านตัวต้านทาน 220Ω - 330Ω ต่อดวง)  
> - **ขาลบ (Cathode / ขาสั้น)** ของ LED ต่อเข้ากับขา **P0 – P11** บนโมดูล PCF8575

### 🎯 2.1 ไฟหลักตรงกลางสำหรับแสดงโจทย์ (Main Sequence LEDs - 4 ดวง)
| หลอดไฟ LED | ขาบน PCF8575 | สัญลักษณ์ในโค้ด |
| :--- | :--- | :--- |
| **ไฟหลัก สีแดง (Red)** | **P0** | `PCF_LED_MAIN_RED` |
| **ไฟหลัก สีเขียว (Green)** | **P1** | `PCF_LED_MAIN_GREEN` |
| **ไฟหลัก สีน้ำเงิน (Blue)** | **P2** | `PCF_LED_MAIN_BLUE` |
| **ไฟหลัก สีเหลือง (Yellow)** | **P3** | `PCF_LED_MAIN_YELLOW` |

### 🔴 2.2 ไฟแสดงผลฝั่งผู้เล่นที่ 1 (Player 1 LEDs - 4 ดวง)
| หลอดไฟ LED | ขาบน PCF8575 | สัญลักษณ์ในโค้ด |
| :--- | :--- | :--- |
| **ไฟ P1 สีแดง (Red)** | **P4** | `PCF_LED_P1_RED` |
| **ไฟ P1 สีเขียว (Green)** | **P5** | `PCF_LED_P1_GREEN` |
| **ไฟ P1 สีน้ำเงิน (Blue)** | **P6** | `PCF_LED_P1_BLUE` |
| **ไฟ P1 สีเหลือง (Yellow)** | **P7** | `PCF_LED_P1_YELLOW` |

### 🔵 2.3 ไฟแสดงผลฝั่งผู้เล่นที่ 2 (Player 2 LEDs - 4 ดวง)
| หลอดไฟ LED | ขาบน PCF8575 | สัญลักษณ์ในโค้ด |
| :--- | :--- | :--- |
| **ไฟ P2 สีแดง (Red)** | **P8** | `PCF_LED_P2_RED` |
| **ไฟ P2 สีเขียว (Green)** | **P9** | `PCF_LED_P2_GREEN` |
| **ไฟ P2 สีน้ำเงิน (Blue)** | **P10** | `PCF_LED_P2_BLUE` |
| **ไฟ P2 สีเหลือง (Yellow)** | **P11** | `PCF_LED_P2_YELLOW` |

*(ขา P12, P13, P14, P15 บนโมดูล PCF8575 เป็นขาว่างสำรอง)*

## 3. การต่อปุ่มกดเล่นเกม 8 ปุ่ม เข้ากับ ESP32 (ฝั่งละ 4 ปุ่ม)

> 🔘 **รูปแบบการต่อปุ่มกด (Active-LOW with Internal Pull-Up)**:  
> สวิตช์ปุ่มกดแต่ละตัวมี 2 ขา:  
> - **ขาที่ 1** ต่อเข้าขา **GPIO ของ ESP32**  
> - **ขาที่ 2** นำมารวมกันแล้วต่อลง **GND** ของ ESP32  
> *(ไม่ต้องต่อตัวต้านทานภายนอกเพิ่ม ใช้ Internal Pull-Up ของ ESP32 ทั้งหมด)*

| ปุ่มกดเล่นเกม | ต่อเข้าขา ESP32 | ขาอีกข้างของปุ่ม | สัญลักษณ์ในโค้ด |
| :--- | :--- | :--- | :--- |
| **ปุ่ม P1 สีแดง (Red)** | **GPIO 16** | **GND** | `PIN_P1_RED` |
| **ปุ่ม P1 สีน้ำเงิน (Blue)** | **GPIO 17** | **GND** | `PIN_P1_BLUE` |
| **ปุ่ม P1 สีเขียว (Green)** | **GPIO 18** | **GND** | `PIN_P1_GREEN` |
| **ปุ่ม P1 สีเหลือง (Yellow)** | **GPIO 19** | **GND** | `PIN_P1_YELLOW` |
| **ปุ่ม P2 สีแดง (Red)** | **GPIO 23** | **GND** | `PIN_P2_RED` |
| **ปุ่ม P2 สีเขียว (Green)** | **GPIO 25** | **GND** | `PIN_P2_GREEN` |
| **ปุ่ม P2 สีน้ำเงิน (Blue)** | **GPIO 26** | **GND** | `PIN_P2_BLUE` |
| **ปุ่ม P2 สีเหลือง (Yellow)** | **GPIO 27** | **GND** | `PIN_P2_YELLOW` |

---

## 4. การต่อปุ่มควบคุม 4 ปุ่ม (Control Buttons) เข้ากับ ESP32

> 🔘 **รูปแบบการต่อเหมือนปุ่มเล่นเกม**: ขาข้างหนึ่งเข้า GPIO และขาอีกข้างต่อลง **GND**

| ปุ่มควบคุม | ฟังก์ชันการทำงาน | ต่อเข้าขา ESP32 | ขาอีกข้างของปุ่ม | สัญลักษณ์ในโค้ด |
| :--- | :--- | :--- | :--- | :--- |
| **ปุ่ม START** | เริ่มเกม / ยืนยัน | **GPIO 32** | **GND** | `PIN_BTN_START` |
| **ปุ่ม NEXT** | ถัดไป / เลือกโหมด | **GPIO 33** | **GND** | `PIN_BTN_NEXT` |
| **ปุ่ม PREV** | ก่อนหน้า | **GPIO 4** | **GND** | `PIN_BTN_PREV` |
| **ปุ่ม RESTART** | รีเซ็ต / เริ่มรอบใหม่ | **GPIO 5** | **GND** | `PIN_BTN_RESTART` |

---

## 5. การต่อ Passive Buzzer

| ขาของ Buzzer Module | ต่อเข้าขา ESP32 | คำอธิบาย |
| :--- | :--- | :--- |
| **Signal (I/O หรือ +)** | **GPIO 13** | สัญญาณขับความถี่เสียง PWM (`PIN_BUZZER`) |
| **VCC** *(ถ้าใช้โมดูล 3 ขา)* | **5V / 3V3** | ไฟเลี้ยงวงจรขับ Buzzer |
| **GND (-)** | **GND** | กราวด์ร่วม |

## ⚠️ ข้อควรระวังและคำแนะนำเชิงเทคนิคสำหรับช่างประกอบ

1. **การเลือกรุ่นของชิปบอร์ด ESP32 (สำคัญมาก)**:
   - **ต้องใช้บอร์ดรุ่น ESP32-WROOM-32 (รุ่นมาตรฐานทั่วไป ไม่มี PSRAM)** เท่านั้น ซึ่งสามารถใช้งานขา `GPIO 16` และ `GPIO 17` ได้อย่างอิสระ
   - ❌ **ห้ามใช้บอร์ดรุ่น ESP32-WROVER** (รุ่นที่มีชิป PSRAM ฝังในตัว) เพราะขา `GPIO 16` และ `GPIO 17` ถูกต่อเชื่อมภายในกับหน่วยความจำ PSRAM หากนำมาต่อปุ่มกดจะทำให้โปรแกรมแครชทันที

2. **การต่อวงจรขับ Active Buzzer**:
   - หากใช้ตัว Buzzer เปลือย 2 ขา (ไม่มีบอร์ดขับ) ซึ่งอาจกินกระแสมากกว่า 12-20mA เกินพิกัดปลอดภัยของ GPIO **แนะนำให้ต่อผ่านทรานซิสเตอร์ NPN (เช่น 2N2222, S8050, หรือ SS8050)** โดยให้ GPIO 13 สั่งเข้าขา Base ผ่าน R 1kΩ เพื่อยืดอายุการใช้งานของบอร์ด ESP32
   - หากใช้ **โมดูล Active Buzzer สำเร็จรูป (แบบ 3 ขา: VCC, GND, I/O)** สามารถต่อขา I/O ตรงเข้า `GPIO 13` ได้ทันทีเพราะมีทรานซิสเตอร์ขับอยู่บนโมดูลแล้ว

3. **ข้อควรระวังเรื่อง Strapping Pins (GPIO 0, 2)**:
   - ขา **GPIO 0** และ **GPIO 2** เป็น Strapping Pins ที่ควบคุมโหมดการ Boot/Flash Firmware ของ ESP32 
   - ในผังนี้ถูกปล่อยว่างไว้ ไม่ถูกนำมาต่อกับปุ่มหรือโหลดใดๆ เพื่อป้องกันไม่ให้ระดับแรงดันไฟผิดพลาดจนบอร์ดบูตไม่ติด

## 📊 ตารางสรุปภาพรวมขาทั้งหมดบนบอร์ด ESP32 Dev Module

```text
               +----------------------+
               |    ESP32 DEV BOARD   |
               |    (ESP32-WROOM-32)  |
               +----------------------+
                     3V3 |  | GND
                      EN |  | GPIO 23 ---> ปุ่ม P2 แดง
                 GPIO 36 |  | GPIO 22 ---> PCF8575 (SCL)
                 GPIO 39 |  | GPIO 1  (TX0)
                 GPIO 34 |  | GPIO 3  (RX0)
                 GPIO 35 |  | GPIO 21 ---> PCF8575 (SDA)
      ปุ่ม START <--- GPIO 32 |  | GND
       ปุ่ม NEXT <--- GPIO 33 |  | GPIO 19 ---> ปุ่ม P1 เหลือง
      ปุ่ม P2 เขียว <--- GPIO 25 |  | GPIO 18 ---> ปุ่ม P1 เขียว
      ปุ่ม P2 น้ำเงิน <--- GPIO 26 |  | GPIO 5  ---> ปุ่ม RESTART
      ปุ่ม P2 เหลือง <--- GPIO 27 |  | GPIO 17 ---> ปุ่ม P1 น้ำเงิน (WROOM only)
       ปุ่ม PREV <--- GPIO 4  |  | GPIO 16 ---> ปุ่ม P1 แดง (WROOM only)
      Buzzer (+) <--- GPIO 13 |  | GPIO 0  (ห้ามใช้ - Boot Pin)
                     GND |  | GPIO 2  (ห้ามใช้ - Boot Pin)
                      5V |  | GPIO 15
               +----------------------+
```
