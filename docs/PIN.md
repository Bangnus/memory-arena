# 📌 คู่มือและตารางการต่อสายวงจร Memory Arena (Hardware Wiring Guide)

เอกสารสรุปแผนผังการต่อสายไฟของเครื่องเล่นเกม **Memory Arena** สำหรับช่างประกอบฮาร์ดแวร์  
ระบบใช้บอร์ด **ESP32 Dev Module ตัวเดียว (ไม่ต้องใช้โมดูลขยายขา PCF8575)**

### 📦 อุปกรณ์หลักประกอบด้วย:
1. **ESP32 Dev Module (รุ่น ESP32-WROOM-32)** x 1 ตัว
2. **หลอดไฟ LED แสดงโจทย์หลักตรงกลาง 4 ดวง**: (แดง, เขียว, น้ำเงิน, เหลือง)
3. **ปุ่มกดเล่นเกม 8 ปุ่ม**: ฝั่งละ 4 ปุ่ม (P1: แดง, น้ำเงิน, เขียว, เหลือง / P2: แดง, เขียว, น้ำเงิน, เหลือง)  
   *(ไฟของปุ่มผู้เล่นจะติดสว่างทันทีเมื่อกด โดยต่อวงจรร่วมกับสวิตช์บน Breadboard)*
4. **ปุ่มควบคุม 4 ปุ่ม**: START, NEXT, PREV, RESTART
5. **Passive Buzzer (หรือโมดูล Buzzer) 1 ตัว**
6. **ตัวต้านทาน (Resistors)**: 220Ω – 330Ω สำหรับ LED ทุกดวง

---

## 1. การต่อหลอดไฟ LED หลักตรงกลางสำหรับแสดงโจทย์ (4 ดวง)

> 💡 **รูปแบบการต่อ LED หลัก (Active-HIGH)**:  
> ขา **GPIO ของ ESP32** ➔ **ตัวต้านทาน 220Ω** ➔ **ขาบวก (Anode / ขายาว)** ของ LED  
> ส่วน **ขาลบ (Cathode / ขาสั้น)** ➔ ต่อลง **GND ร่วม**

| หลอดไฟ LED หลัก (แสดงโจทย์) | ต่อเข้าขา ESP32 | คำอธิบาย | สัญลักษณ์ในโค้ด |
| :--- | :--- | :--- | :--- |
| 🔴 **ไฟหลัก สีแดง (Red)** | **GPIO 21** | สัญญาณขับ LED แดง | `PIN_LED_MAIN_RED` |
| 🟢 **ไฟหลัก สีเขียว (Green)** | **GPIO 22** | สัญญาณขับ LED เขียว | `PIN_LED_MAIN_GREEN` |
| 🔵 **ไฟหลัก สีน้ำเงิน (Blue)** | **GPIO 14** | สัญญาณขับ LED น้ำเงิน | `PIN_LED_MAIN_BLUE` |
| 🟡 **ไฟหลัก สีเหลือง (Yellow)** | **GPIO 15** | สัญญาณขับ LED เหลือง | `PIN_LED_MAIN_YELLOW` |

---

## 2. การต่อปุ่มกดเล่นเกม 8 ปุ่ม + ไฟแสดงผลตอนกด (Breadboard Circuit)

> 🔘 **รูปแบบการต่อวงจรปุ่มกดพร้อมไฟติดเมื่อกด (Active-LOW + LED Indicator)**:
> 
> ```text
>               [ + รางไฟ 3.3V ของ ESP32 ]
>                          │
>                   [ ตัวต้านทาน 220Ω ]
>                          │
>                     [ ขาบวก (+) ขายาวของ LED ]
>                     [ ขาลบ  (-) ขาสั้นของ LED ]
>                          │
>         ┌────────────────┴────────────────┐
>         │                                 │
>  [ ขา GPIO ของ ESP32 ]             [ ขาที่ 1 ของปุ่มกด ]
>                                    [ ขาที่ 2 ของปุ่มกด ]
>                                           │
>                                 [ - ราง GND ของ ESP32 ]
> ```
> * **เมื่อยังไม่กด**: ESP32 อ่านค่าเป็น `HIGH`, หลอด LED ดับ
> * **เมื่อกดปุ่ม**: ESP32 อ่านค่าเป็น `LOW`, หลอด LED สว่างทันทีตามแรงกด

### 🔴 2.1 ปุ่มฝั่งผู้เล่นที่ 1 (Player 1 - 4 ปุ่ม)
| ปุ่มกดเล่นเกม P1 | ขาสัญญาณ ESP32 (จุดต่อขาลบ LED) | ขาอีกข้างของปุ่ม | สัญลักษณ์ในโค้ด |
| :--- | :--- | :--- | :--- |
| **ปุ่ม P1 สีแดง (Red)** | **GPIO 16** | **GND** | `PIN_P1_RED` |
| **ปุ่ม P1 สีน้ำเงิน (Blue)** | **GPIO 17** | **GND** | `PIN_P1_BLUE` |
| **ปุ่ม P1 สีเขียว (Green)** | **GPIO 18** | **GND** | `PIN_P1_GREEN` |
| **ปุ่ม P1 สีเหลือง (Yellow)** | **GPIO 19** | **GND** | `PIN_P1_YELLOW` |

### 🔵 2.2 ปุ่มฝั่งผู้เล่นที่ 2 (Player 2 - 4 ปุ่ม)
| ปุ่มกดเล่นเกม P2 | ขาสัญญาณ ESP32 (จุดต่อขาลบ LED) | ขาอีกข้างของปุ่ม | สัญลักษณ์ในโค้ด |
| :--- | :--- | :--- | :--- |
| **ปุ่ม P2 สีแดง (Red)** | **GPIO 23** | **GND** | `PIN_P2_RED` |
| **ปุ่ม P2 สีเขียว (Green)** | **GPIO 25** | **GND** | `PIN_P2_GREEN` |
| **ปุ่ม P2 สีน้ำเงิน (Blue)** | **GPIO 26** | **GND** | `PIN_P2_BLUE` |
| **ปุ่ม P2 สีเหลือง (Yellow)** | **GPIO 27** | **GND** | `PIN_P2_YELLOW` |

---

## 3. การต่อปุ่มควบคุม 4 ปุ่ม (Control Buttons)

> 🔘 **รูปแบบการต่อปุ่มควบคุม**: ขาข้างหนึ่งเข้า GPIO และขาอีกข้างต่อลง **GND** (ใช้ Internal Pull-Up)

| ปุ่มควบคุม | ฟังก์ชันการทำงาน | ต่อเข้าขา ESP32 | ขาอีกข้างของปุ่ม | สัญลักษณ์ในโค้ด |
| :--- | :--- | :--- | :--- | :--- |
| **ปุ่ม START** | เริ่มเกม / ยืนยัน | **GPIO 32** | **GND** | `PIN_BTN_START` |
| **ปุ่ม NEXT** | ถัดไป / เลือกโหมด | **GPIO 33** | **GND** | `PIN_BTN_NEXT` |
| **ปุ่ม PREV** | ก่อนหน้า | **GPIO 4** | **GND** | `PIN_BTN_PREV` |
| **ปุ่ม RESTART** | รีเซ็ต / เริ่มรอบใหม่ | **GPIO 5** | **GND** | `PIN_BTN_RESTART` |

---

## 4. การต่อ Buzzer

| ขาของ Buzzer | ต่อเข้าขา ESP32 | คำอธิบาย |
| :--- | :--- | :--- |
| **Signal (I/O หรือ +)** | **GPIO 13** | สัญญาณขับความถี่เสียง PWM (`PIN_BUZZER`) |
| **GND (-)** | **GND** | กราวด์ร่วม |

## ⚠️ ข้อควรระวังเชิงเทคนิคสำหรับช่างประกอบ

1. **การเลือกรุ่นของชิปบอร์ด ESP32**:
   - **ต้องใช้บอร์ดรุ่น ESP32-WROOM-32 (รุ่นมาตรฐานทั่วไป)** ซึ่งสามารถใช้งานขา `GPIO 16` และ `GPIO 17` ได้อย่างอิสระ
   - ❌ **ห้ามใช้บอร์ดรุ่น ESP32-WROVER** (รุ่นที่มีชิป PSRAM ฝังในตัว) เพราะขา `GPIO 16` และ `GPIO 17` ต่อเชื่อมกับหน่วยความจำ PSRAM

2. **ข้อควรระวังเรื่อง Strapping Pins (GPIO 0, 2)**:
   - ขา **GPIO 0** และ **GPIO 2** ถูกปล่อยว่างไว้ ไม่นำมาต่อกับโหลดใดๆ เพื่อป้องกันไม่ให้ระดับแรงดันไฟผิดพลาดตอนบูต

## 📊 ตารางสรุปภาพรวมขาทั้งหมดบนบอร์ด ESP32 Dev Module (รวม 17 ขา)

```text
               +----------------------+
               |    ESP32 DEV BOARD   |
               |    (ESP32-WROOM-32)  |
               +----------------------+
                      3V3 |  | GND
                       EN |  | GPIO 23 ---> ปุ่ม P2 แดง
                  GPIO 36 |  | GPIO 22 ---> ไฟหลัก สีเขียว
                  GPIO 39 |  | GPIO 1  (TX0)
                  GPIO 34 |  | GPIO 3  (RX0)
                  GPIO 35 |  | GPIO 21 ---> ไฟหลัก สีแดง
       ปุ่ม START <--- GPIO 32 |  | GND
        ปุ่ม NEXT <--- GPIO 33 |  | GPIO 19 ---> ปุ่ม P1 เหลือง
       ปุ่ม P2 เขียว <--- GPIO 25 |  | GPIO 18 ---> ปุ่ม P1 เขียว
       ปุ่ม P2 น้ำเงิน <--- GPIO 26 |  | GPIO 5  ---> ปุ่ม RESTART
       ปุ่ม P2 เหลือง <--- GPIO 27 |  | GPIO 17 ---> ปุ่ม P1 น้ำเงิน (WROOM only)
       ไฟหลัก น้ำเงิน <--- GPIO 14 |  | GPIO 16 ---> ปุ่ม P1 แดง (WROOM only)
       Buzzer (+) <--- GPIO 13 |  | GPIO 0  (ห้ามใช้ - Boot Pin)
                      GND |  | GPIO 2  (ห้ามใช้ - Boot Pin)
       ไฟหลัก เหลือง <--- GPIO 15 |  | GPIO 4  ---> ปุ่ม PREV
               +----------------------+
```
